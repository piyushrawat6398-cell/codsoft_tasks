# CODSOFT_TASKSN0.
ATM Interface – Java

About the Project

This is a console-based ATM Interface developed using Java and Object-Oriented Programming concepts as part of the CodSoft Java Development Internship.

Features

- Check account balance
- Deposit money
- Withdraw money
- Insufficient funds validation
- Invalid amount validation
- Interactive ATM menu

Technologies Used

- Java
- IntelliJ IDEA
- Object-Oriented Programming

Classes

1. Main – Application entry point
2. Account – Manages account balance and transactions
3. ATM – Handles ATM operations and menu

Initial Balance

Rs. 10,000

How to Run

1. Download or clone this repository.
2. Open the project in IntelliJ IDEA.
3. Run Main.java.
