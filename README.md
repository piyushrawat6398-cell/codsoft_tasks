# CODSOFT_TASKSN0.
CODSOFT Java Programming Internship

This repository contains the Java projects completed as part of my CodSoft Java Programming Internship.

Projects

Task 1: Number Guessing Game

- Generates a random number between 1 and 100.
- Gives hints when the guess is too high or too low.
- Provides a limited number of attempts.
- Includes replay functionality and scoring.

Task 2: Student Grade Calculator

- Accepts marks for five subjects.
- Calculates total marks and average percentage.
- Assigns grades based on the average.
- Displays pass or fail status.
- Validates marks entered by the user.

Task 3: ATM Interface

- Provides a console-based ATM interface.
- Supports balance checking.
- Allows deposits and withdrawals.
- Checks for insufficient funds.
- Uses object-oriented programming concepts.

- ArrayList / Random / Scanner (where applicable)
